My exercises and assignments from an object-oriented programming in C++ course (COP2334, spring 2020). Archived coursework, organized by module. Some prompts and comments are in Turkish.

### ✨ What's inside
- 🧮 `module3`: first programs with I/O and formatting (tip and tax calculators, area calculator, random number generator)
- 📂 `module4`, `module5`: loops, reading and writing text files, and functions
- 🔢 `module6`: arrays (removing, reversing, and showing elements)
- 🧱 `module7`, `module9`: classes (`Rectangle`) and inheritance (`Dinosaur` / `TRex`)
- 👉 `module8`, `module10`: pointers and C++ strings (`PasswordVerifier`)
- 📚 `module11` to `module13`, `moduleFINAL`: copy constructors and operator overloading, vectors, lambdas, and the final exam (`Invertebrate` / `Snail`)
- 🗂️ `codes/`: early copy of the module 3 files plus `odev.cpp`, which writes a student's name and number to a text file; `container.cpp` is a standalone container loading exercise

### 🚀 Quick start
Every `.cpp` file is its own program. Compile and run one with any C++11 compiler:
```bash
git clone https://github.com/canmenzo/CppExamples.git
cd CppExamples
g++ -std=c++11 module9/dinos-trex.cpp -o dinos && ./dinos
```
